# Soybean crop model benchmark

**Status:** feasibility and protocol design; no datasets acquired, models run or results reported.

## Proposed research question
How do eligible soybean yield prediction models compare under consistent observation, input availability, calibration and held-out evaluation conditions in Brazil, potentially the Cerrado?

Candidate families for investigation include DSSAT, APSIM, other eligible crop simulators, statistical baselines and machine learning. Inclusion is conditional on verified soybean support, access, licensing, comparable outputs and reproducible execution. This is not a confirmed list of runnable models.

## First task
Complete the [model inventory](models/README.md) and [data inventory](data/README.md); finalize the [protocol](PROTOCOL.md) before calibration or testing. Identify an observation dataset that can legally be used. The existing yield-gap research is separate; its data may not be reused without permission.
